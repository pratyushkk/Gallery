Engineered for Performance

Every frame, decode pipeline, and gesture touch event is fine-tuned for high-refresh Android hardware.

90Hz & 120Hz Fluid Motion

Calculated frame budgets (11.1ms for 90Hz, 8.3ms for 120Hz). Heavy bitmap decodes, MediaStore queries, and crypto run off the UI thread via Kotlin Coroutines.

32-Bit Razor Previews

Direct uncompressed stream decoding with hardware-backed ARGB_8888 color. Eliminates blurry 70% micro-thumbnails and muddy RGB_565 AMOLED color banding.

Biometric Vault (Locker)

Hardware-backed Android BiometricPrompt (Fingerprint / Face / PIN) with AES-256 GCM encryption. Hidden from other apps and safe in isolated app storage.

Full Swipe & Gesture Physics

Swipe horizontally across bottom menu tabs (Photos • Albums • Search) and swipe seamlessly between full-screen photos with synchronized bottom filmstrip scrubbing.

30-Day Recycle Bin

Prevents accidental data loss. Media can be recovered anytime within 30 days or permanently purged with a single tap.

Real-Time Sync & Search

ContentObserver monitors MediaStore for external camera captures, downloads, and deletions. Instant search with smart category filters.
